# Lattice Forge

Design construction utilities for *Lattice Forge: Design Construction for
Computer Experiments* (Journal of Lattice Methods, 2026).

The package builds space-filling designs with strong one-dimensional
projection properties and reports standard diagnostics.

## Layout

- `src/lattice.py` — construction and projection diagnostics
- `data/design_16x4.csv` — the 16-run, 4-factor design from Section 5
- `experiments/generate_design.py` — CLI wrapper for building a design
